# LumaBrake v1.0.0

LumaBrake v1.0.0 is the first public showcase release of the Windows app, with refreshed documentation, real application screenshots, and verified release packages.

## Downloads

- `LumaBrake-win-x64-portable.zip`
- `LumaBrake-win-x64-portable.zip.sha256`
- `LumaBrake-win-x64-setup.msi`
- `LumaBrake-win-x64-setup.msi.sha256`
- `LumaBrake.cdx.json`

## Highlights

- Introduces the public LumaBrake product page and download flow.
- Adds current screenshots for Overview, Monitors, Night Color, Rules, Diagnostics, and Settings.
- Includes brightness spike protection, Flash Guard, StaticShade, adaptive dimming, OLED Care, Night Color, profiles, rules, diagnostics, tray controls, and CLI support.
- Ships verified portable and installer artifacts with checksums.
- Keeps repository-facing product text in English.

## Notes

- The build is unsigned, so Windows may show SmartScreen or publisher warnings.
- HDR, protected content, exclusive full-screen apps, and some display drivers may limit capture or overlay behavior.
- LumaBrake is a visual comfort utility and does not guarantee medical or OLED burn-in prevention outcomes.
